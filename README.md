# Курсовая работа 
Программа разработана на Python для сортировки банковских операций
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/course_work_1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание работы функций
### Модуль *masks*
1. Функция *get_mask_card_number* принимает на вход тип и номер карты в виде строки и возвращает маску номера по правилу: name_card
    XXXX XX** **** XXXX.
2. Функция *get_mask_account* принимает на вход номер счета в виде строки и возвращает маску номера по правилу: Счет
    **XXXX.
### Модуль *widget*
1. Функция *mask_account_card* принимает на вход тип и номер карты или номер счета в виде строк и возвращает маски карты или счета по правилу:
    name_card XXXX XX** **** XXXX или Счет **XXXX.
2. Функция *get_date* принимает на вход дату и время и возвращает строку в виде: ДД.ММ.ГГГГ.
### Модуль *processing*
1. Функция *filter_by_state* принимает список словарей и опционально значение для ключа (по умолчанию 'EXECUTED') и возвращает новый список словарей state_list, содержащий только те словари,
    у которых ключ соответствует указанному значению).
2. Функция *sort_by_date* принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание)
    и возвращает список, отсортированный по дате.
### Модуль *generators*
1. Функция *filter_by_currency* принимает список описания банковских операций и опциональное значение (валюту, по умолчанию "USD") и возвращает новый список, содержащий только те операции,
    в которых указана заданная валюта.
2. Функция *transaction_descriptions* принимает список описания банковских операций и возвращает описание каждой операции по очереди.
3. Функция *card_number_generator* генерирует номер карты в виде ХХХХ ХХХХ ХХХХ ХХХХ основываясь на заданных значениях начала и конца
    генерации от 0000 0000 0000 0000 до 9999 9999 9999 9999
### Модуль *decorators*
1. Декоратор принимает на вход параметр filename(название файла) и записывает в него результат выполнения функцию.
Если параметр не задан, то результаты выводятся в консоль.
2. Функция прописана в модуле *main.py*, при необходимости можно изменить выражения или вводимые параметры, для оценки работы
3. Результаты работы выводятся в консоль (если не задан параметр filename), либо в файл с расширением *.txt*(по умолчанию прописан в модуле *main.py*)
### Модуль *utils*
1. Функция *valute_transaction* извлекает список транзакций из файла *operations.json*
### Модуль *external_api*
1. Функция *operation_amount* принимает список транзакций из модуля *utils* и выводит сумму каждой транзакции в рублях, если транзакция была не в рублях, то производится запрос к внешнему источнику для конвертирования суммы
### Модуль *reading_data*
1. Функция *open_csv_file* считывает финансовые операции из файла .csv по указываемому и выдает список словарей с транзакциями
2. Функция *open_excel_file* считывает финансовые операции из файла .xlsx по указываемому пути и выдает список словарей с транзакциями
### Модули *main.py* и *transactions_for_user.py*
1. Функция *main* является основной функцией для запуска программы, она считывает информацию из выбранного файла и передает в модуль transactions_for_user, производит сбор информации от пользователя через запросы, сортирует транзакции на основании выбора пользователя и выводит результат выполнения работы программы
2. Функция *process_bank_search* в модуле *transactions_for_user.py* принимает список транзакций от *main* и параметр *search*, по которому необходимо произвести сортировку и возвращает отсортированный список
3. Функция *counter_operations* в модуле *transactions_for_user.py* принимает список транзакций от *main* и посчитывает операции по категориям в описании каждой операции, а далее возвращает словарь с количеством каждых операций
## Использование программы
1. В модуле *main.py* прописана программа по сортировке транзакций, для работы программы необходимо нажать *Run* в конце модуля и работа программы начнется.
2. Остальные функции запускаются из своих модулей путем указания в конце модуля типового вызова функции(прописан ниже), где *func* - название вызываемой функции, *args* - данные, необходимые для работы функции, согласно условия
```
print(func(args))
```
