# Курсовая работа 
Программа разработана на Python для сортировки банковских операций
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/course_work_1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание работы модулей
### Модуль *views*
1. Функция *views* принимает на вход дату, производит определение времени суток и передает приветствие и
    путь записи конечного файла.
### Модуль *services*
1. Функция *category_cashback* принимает год, месяц и список транзакций, производит вычисление топ-3 категорий кэшбэка и передает словарь
    с категориями и путь записи конечного файла.
### Модуль *reports*
1. Функция *spending_by_category* принимает дату, наименование категории и DataFrame с транзакциями, производит сортировку
    по дате(последние три месяца от указанной даты) и категории и возвращает отсортированный DataFrame.
### Модуль *utils* (вспомогательные функции)
1. Функция *open_excel_file* считывает финансовые операции из файла .xlsx по указываемому пути и выдает список словарей с транзакциями.
2. Функция *data_for_json* принимает на вход приветствие и список транзакций и производит выборку необходимых данных
    в соответствии с ТЗ, затем передает словарь с данными для записи в json файл.
3. Функция *write_to_file* принимает на вход словарь с данными по транзакциям, путь файла и производит запись
    данных в этот файл.
### Модуль *main*
1. Главная функция *main* для запуска функций работы программы.
## Использование программы
1. В модуле *main.py* прописана программа по сортировке транзакций, для работы программы необходимо нажать *Run* в конце модуля и работа программы начнется.
```
print(func(args))
```
